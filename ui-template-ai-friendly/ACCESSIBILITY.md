# Accessibility Baseline

- Gunakan elemen semantik sesuai fungsi: button untuk aksi, link untuk navigasi, label untuk input.
- Semua fungsi utama dapat digunakan dengan keyboard.
- Fokus keyboard terlihat.
- Input memiliki label dan error terkait yang dapat dikenali teknologi bantu.
- Kontras teks dan kontrol memadai.
- Informasi status tidak hanya dibedakan dengan warna.
- Gambar informatif memiliki alternative text; gambar dekoratif tidak mengganggu pembaca layar.
- Heading berurutan dan mencerminkan struktur konten.
- Target interaksi cukup besar dan memiliki jarak yang memadai.
- Jangan menghilangkan outline fokus tanpa pengganti yang setara.
- Uji dengan pemeriksaan otomatis dan manual jika alat tersedia; laporkan cakupan pengujian.
