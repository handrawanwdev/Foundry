# Data Table Pattern Example

## Struktur
1. Page header: judul, deskripsi opsional, aksi utama.
2. Toolbar: search/filter jika didukung use case.
3. Table: kolom prioritas, status, dan aksi kontekstual.
4. Footer: informasi pagination bila tersedia.

## Rules
- Label kolom singkat dan konsisten.
- Angka diratakan sesuai konvensi proyek.
- Status menggunakan label yang jelas.
- Empty state menjelaskan cara membuat atau menemukan data.
- Aksi destructive dipisahkan dari aksi rutin.
- Pada layar kecil, pilih scroll yang jelas atau pola alternatif tanpa menghilangkan konteks.
