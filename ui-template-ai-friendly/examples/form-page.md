# Form Page Pattern Example

## Struktur
1. Page header: judul dan tujuan form.
2. Form sections: kelompok field berdasarkan makna.
3. Field: label, kontrol, helper text jika perlu, dan error terkait.
4. Form actions: aksi utama dan cancel dengan hirarki yang jelas.

## Rules
- Jangan memakai placeholder sebagai satu-satunya label.
- Pertahankan nilai input saat validasi gagal.
- Tempatkan error dekat field terkait.
- Tampilkan status saat menyimpan.
- Cegah submit ganda bila relevan.
- Jangan mengarang validasi backend; verifikasi kontrak yang ada.
