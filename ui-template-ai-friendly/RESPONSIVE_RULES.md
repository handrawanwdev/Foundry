# Responsive Rules

- Rancang berdasarkan kebutuhan konten, bukan hanya nama perangkat.
- Hindari horizontal overflow pada viewport kecil kecuali konten memang membutuhkan pola scroll yang jelas.
- Form menjadi satu kolom ketika dua kolom membuat label atau input terlalu sempit.
- Tabel kompleks dapat memakai scroll horizontal atau pola alternatif yang menjaga keterbacaan; jangan sembarang menyembunyikan kolom penting.
- Sidebar mengikuti pola responsif yang sudah dipakai aplikasi.
- Dialog tidak boleh melampaui viewport dan tetap dapat digunakan pada layar kecil.
- Kontrol utama tetap mudah dijangkau dengan pointer dan keyboard.
- Uji setidaknya viewport sempit, menengah, dan lebar jika browser/tooling tersedia.
- Jangan mengklaim sudah diuji secara visual bila browser tidak dijalankan.
